Honorverse Hyper Limits — diagram options

Mockup only — nothing in the app was changed. Option 14's chart today is 44 horizontal bars (one per catalogue row), scroll-wrapped to ~16 inches tall. Below are five ways to show the same data in one screen, grouped by spectral class (O · B · A · F · G · K · M · Red Giant) and drawn in the ring/reference-line idiom the HZ, snow-line and ice-line diagrams already use.

The underlying numbers are perfectly regular: F0 → M9 falls by a constant ~0.44 LM per subtype (26.42 → 9.24 LM), so the 40 subtype rows are one straight line, not 40 facts. O/B/A each have a single value, and "Red Giant" is a lone outlier at 5.64 LM. That is the argument for collapsing — and for showing the trend rather than enumerating it.

Option A — Class range bands8 bars, all 44 values kept

One bar per class letter, spanning that class's hottest → coolest hyper limit, with a faint tick for every subtype inside the band and the endpoints labelled (e.g. F: F0 3.18 AU → F9 2.70 AU). Single-value classes (O, B, A, Red Giant) draw as a short capsule. This is the same idiom as the Solvent liquid-range chart (Phase P V5), so it will look native. Nothing is hidden — the subtypes are ticks.

Good

  • Fits one screen — no scroll wrapper needed.
  • Keeps every catalogue value visible as a tick.
  • Shows class spread, which the 44-bar chart buries.

Costs

  • Exact per-subtype numbers need hover (or the table beside it).
  • New prep + canvas (a range chart, not a bar chart).

Option B — Spectral sequence line1 line, 44 points

X = the spectral sequence in catalogue order (O → M9), Y = hyper limit. Class letters become shaded backdrop bands with the letter in the margin. The whole table becomes one monotone curve, which makes the constant 0.44 LM/subtype step and the O/B/A jumps immediately obvious. Red Giant sits off-sequence, so it is drawn as a separate dashed reference line rather than a 45th point on the curve.

Good

  • Densest, most honest reading of the data's actual shape.
  • Every one of the 44 values is a real plotted point.
  • Cheapest to build — a line chart over the existing prep.

Costs

  • Reads as an analysis chart, not a lookup table.
  • Red Giant has to be handled as an exception.

Option C — Concentric class rings√AU, snow-line idiom

The direct analogue of the Ice Line / System Regions ring maps: a star at centre, one dashed ring per class letter on a √AU scale, each labelled G · 2.65–2.17 AU. Where a class covers a range, the ring is drawn as a thin shaded annulus between its hottest and coolest subtype, so you can see the classes interleave outward. Red Giant is the innermost ring, O the outermost.

Good

  • Visually consistent with every other "distance from the star" diagram.
  • Reads as a physical distance, which is what a hyper limit is.
  • Only 8 labels on screen.

Costs

  • √ compression makes small differences hard to compare precisely.
  • Rings crowd in the F/G/K/M middle — the four bands nearly touch.
  • Most work to build of the five.

Option D — Reference-line stripclosest to Snow Line / Tidal Lock

A single horizontal AU axis — the HZ Strip layout — with each class drawn as a labelled dashed vertical reference line, exactly the way the water snow line is drawn. Optionally the 40 subtypes appear as faint hairlines behind the 8 named ones, so the class letters stay legible while the full catalogue is still on the axis. This is also the layout that would drop straight onto an existing HZ strip as an overlay, if you ever want "where does the hyper limit fall vs the habitable zone".

Good

  • Exactly the Snow-Line treatment you asked about.
  • Compact — ~200 px tall, no scrolling.
  • Composes with the HZ strip as a real overlay later.

Costs

  • Labels collide in the F/G/K/M cluster unless staggered (shown staggered here).
  • Least useful as a standalone "table replacement".

Option E — Collapsed bars + drill-downkeeps today's bar chart

Smallest change: keep the current horizontal bar chart, but plot 8 class bars (bar = the class's coolest limit, whisker out to its hottest) and add a class selector. Pick F and the chart swaps to F0–F9's ten bars — the existing 44-bar rendering, just one class at a time. "All subtypes" restores today's view for anyone who wants it.

Good

  • Reuses the existing canvas almost as-is; lowest risk.
  • Nothing is lost — today's view is one dropdown away.

Costs

  • Needs a control widget in the viz tab (none there today).
  • Grouped view alone doesn't show the linear trend the way B does.

Catalogue (for reference)

44 rows, straight from spTypeHyperLM.csv. AU = LM ÷ 8.3167.

Notes · All five keep the app's spectral palette (core.shared._SPECTRAL_COLORS) so a class reads the same colour here as on the star charts; because F/G/A are near-white by design, identity is carried by the label, never the hue alone. · The per-star hyper-limit ring on opts 8/9/13 and the orbital-diagram ring (Phase O O10b) are unaffected by any of this — this is only the option-14 reference chart. · Mockup file, not wired to the app.
