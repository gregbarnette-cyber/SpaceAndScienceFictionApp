System Architecture Map PHASE 3 · NEW

A whole-system schematic: every star placed by a recursive Jacobi barycenter roll-up (each binary splits its two components about their mass-weighted barycenter, offset = sep × mother/(m₁+m₂)), then mapped log-radially from the system barycenter so ~6 orders of scale (Proxima at 15 000 AU ↔ α Cen A/B at 23 AU ↔ planets at <1 AU) coexist. Planets ride as small log-scaled rings on their host. Click a component to recenter.
Phase 3 build checklist (what this mockup is asking you to approve)
  • Static layout (D5). Mass-weighted barycenter at the origin via recursive Jacobi roll-up; each <binary> splits its two children by sep×m_other/(m₁+m₂). Separation resolved as: semimajoraxis (AU) → separation[unit=AU] → separation[arcsec]×distance_pc (projected AU) → Kepler fallback a=∛((M₁+M₂)·P²) from the binary period when only a period is catalogued (61 Cygni — labelled "from period"). Geometric-midpoint fallback (equal split + a ⚠ flag) when a component mass is missing; components stay stacked at the barycenter only if no separation, sma, or period exists. ← new rung vs. D5's ladder — flag if you'd rather 61 Cyg just stack/schematic-offset.
  • Log-radial mapping. Angle = on-sky positionangle (deterministic schematic angle when absent); radius = log-scaled barycentric distance. Faint decade rings label the AU scale. A single star sits at the barycenter (origin).
  • Planets = small rings on their host, log-scaled by semi-major axis; RV-only planets (no radius) still shown; M·sin i and status carried through.
  • Interactive click-to-recenter. Click a star → focus it (planets expand to fill) and repopulate the Phase-2 per-host tabs — the map replaces the host combo. Click a binary node → re-anchor on that subsystem's barycenter (spreads a collapsed tight pair like α Cen A/B apart). A breadcrumb + ⟲ Reset to barycenter return to the whole-system view.
  • Caveat labeling (honesty). Projected separation (arcsec→AU is a sky projection, not true 3-D); static placement (positionangle = on-sky orientation, no orbital phase) — an architecture sketch, not an ephemeris. Rendered as a persistent footnote.
  • New code only: core.viz.prepare_oec_architecture(system_node) (pure layout → dict of placed nodes/edges/scale) + make_oec_architecture_canvas (matplotlib, dark-navy Star-Chart palette) wired into OecPanel; the click handler reuses the existing Phase-2 _render_host. No change to the core node model, CLI tree, or query.py.
