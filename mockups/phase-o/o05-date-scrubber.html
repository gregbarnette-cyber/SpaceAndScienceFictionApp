O5 · Date Scrubber / Orbital Animation

The System Map already solves Kepler offline for any date — this drives it with a slider so planets sweep their orbits. Only marker offsets move; orbits and star are static artists.

Plan details (from future_phases.md)
  • Slider spans [date − span, date + span], span = min(2× longest period, 50 yr); throttled 50 ms recompute via prepare_exoplanet_system_diagram.
  • Play steps at ~10 fps; updates PathCollection.set_offsets + draw_idle() only.
  • epoch_known=False planets stay pinned at periastron (open-ring overlay) — the scrubber invents no motion for them.
  • Opts 22/23: approximate propagation along circular reference orbits with a persistent “approximate positions” label.
● planet (date-resolved)○ open ring = no epoch (pinned at periastron)
Real app: orbits/star drawn once; only planet markers re-offset per frame — smooth, no Horizons calls during scrubbing.
