Star Systems Search

Filter the local star_systems table by spectral class, distance, apparent magnitude, or designation prefix. No network calls — instant local query.

Plan details
  • Source: local star_systems SQLite table · cap: 500 rows · default sort: Light Years asc
  • Filters: spectral class (chips + subtype/luminosity refine), ly_min/max, mag_min/max, designation_prefix
  • Drill-down: opens the star inline in a new tab (SIMBAD view + Hypatia) — switchable, multiple at once.
  • Fe/H filter = Phase L4 stretch (needs the Hypatia cache) — shown disabled.

HWC Planet Search

Filter the Habitable Worlds Catalog (hwc table) by habitability flags, ESI, mass, radius, temperature, spectral class, and distance. Ranked by Earth Similarity Index. No network calls.

Plan details
  • Source: local hwc SQLite table · cap: 500 rows · default sort: ESI desc
  • Filters: esi_min, habitable / con-HZ / opt-HZ flags, mass_min/max (P_MASS, M⊕), radius_min/max (P_RADIUS, R⊕), temp_min/max, spectral class, ly_max
  • Drill-down: opens the full four-table HWC view for that system inline in a new tab.

NASA Exoplanet Quick Search

Query the live NASA Exoplanet Archive (pscomppars) by planet mass, radius, orbital period, host spectral class, discovery method, distance, and temperature.

Plan details
  • Source: live NASA pscomppars TAP query (background thread) · cap: 200 rows · default sort: SMA asc
  • Filters: pl_bmasse_min/max (M⊕), pl_rade_min/max (R⊕), pl_orbper_min/max (days), spectral class, discoverymethod, st_teff_min/max, sy_dist_max (pc)
  • Drill-down: opens the host star's full system view inline in a new tab.
