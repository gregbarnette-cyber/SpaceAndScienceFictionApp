Hyper Translation Time K1

Travel time for a distance across all 24 hyper bands (Alpha–Omega), per ship type. Uses the 24-band expanded speed table; merchantmen rows beyond Delta are flagged (the * bands they do not normally use).

Plan details
  • compute_hyper_translation_time(distance_ly, ship_type) — self-validating (distance_ly > 0; ship type ∈ warship/merchantship).
  • Per band: speed_ly_hr = speed_xc / 8765.8128; travel_hours = distance_ly / speed_ly_hr; format_travel_time.
  • A 0-speed band → "N/A" (a value, not an error). The * footnote marks bands merchantmen don't normally use.

Impeller Wedge Geometry K2

Effective acceleration and maximum velocities for a ship at a given wedge power, from its mass band. Results update live as you move the slider.

Plan details
  • compute_impeller_wedge(ship_mass_tons, ship_type, wedge_power_pct) — self-validating (mass > 0; 0 < power ≤ 100).
  • effective_accel_g = base_accel_g × power/100; max normal-space velocity cap ≈ 0.8c (warship) / 0.6c (merchant) × power.
  • A mass above the heaviest band clamps to it (noted), not an error.

Missile Intercept K3

Whether a missile from a moving launcher can intercept a moving target at a given range. 1D head-on, non-relativistic (valid at these ×c scales). Target velocity: + = receding (same direction), − = head-on (closing).

Plan details
  • compute_missile_intercept(launcher_vel_xc, missile_accel_g, missile_delta_v_xc, target_vel_xc, range_lm) — self-validating (range/accel/delta-v > 0).
  • Burn to delta-v exhaustion, then coast; v_close = v_burnout − v_target. v_close ≤ 0 → no intercept.
  • intercepts=False is a normal result, not an error.

Engagement

In the real app the verdict is a green/red label and the profile is a make_table(); pure math, no background thread. Bad range / acceleration / delta-v give the red error label.
