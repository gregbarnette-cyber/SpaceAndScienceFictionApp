Multi-Stop Journey Calculator

Cumulative travel time along an ordered list of stops — same 3D-Euclidean distance and format_travel_time as opts 20/21. Enter one stop per line.

Plan details
  • compute_multi_stop_journey(star_names, velocity_input, use_times_c) — self-validating, GUI-only.
  • Per-stop resolution: DB-first (case-insensitive star_name) → SIMBAD fallback; sol/sun → origin.
  • First unresolvable stop → {"error": "Stop N ('name'): …"} (fail-fast; no skip/abort prompt — GUI-only).
  • ≥ 2 stops and velocity > 0 required.

Nearest-Neighbor Chain

From a start star, hop to the closest unvisited star within the max hop distance, building a chain of up to N hops. Reads positions from the local star_systems table.

Plan details
  • compute_nearest_neighbor_chain(start_star, num_hops, max_ly) — self-validating.
  • Start resolved via SIMBAD (sol/sun → origin); the start's own DB row is excluded within 1e-3 ly so it can't be hop 1.
  • No unvisited star within max_ly → chain ends early (not an error: stopped_early=True).

Trade-Route Network Planner STRETCH

Given a set of systems, find the minimum-cost network (minimum spanning tree) that connects them all — Kruskal's algorithm with union-find.

Plan details
  • compute_trade_route_mst(star_names) — self-validating; ≥ 2 systems.
  • Pairwise 3D distances → sort edges ascending → add non-cycle-forming edges until N−1 chosen.
  • Solid edges (vs. the dashed ordered routes of I1/I2). Stretch goal — ships last; I1/I2 work without it.
