GCNS Census Browser LOCAL · instant

All GCNS sources within N light years of Sol — an instant local-DB read (no SIMBAD, no thread). The −σ / +σ columns are the headline: GCNS Bayesian distance uncertainty, nothing else in the app has it. missing_10mas rows (e.g. Alpha Cen A/B — Gaia missed them) show a 1/ϖ point value with no error bar.

Plan details
  • Backed by compute_gcns_within_sol(limit_ly) → {limit_ly, count, snapshot_date, gcns_version, stars[]}.
  • Panel GcnsCensusBrowserPanel(DiagramToggleMixin, ResultPanel); reuses the opt 18/19 map tabs via the heliocentric x/y/z already returned.
  • Optional viz: radial distance-uncertainty indicator from dist_lo_pc/dist_hi_pc in make_star_map_canvas.

GCNS Source Lookup

Full detail for one GCNS source. Enter a name (resolved via SIMBAD → Gaia id) or a raw Gaia source_id (offline, instant). If both are filled, the id wins.

Plan details
  • id path → compute_gcns_by_source_id(id) (instant); name path → _resolve_gcns_row(star=…) (SIMBAD → id → name fallback for missing_10mas).
  • Gaia G/BP/RP kept explicitly separate from Johnson V (app_magnitude). Spectral type from SIMBAD cross-match; never fabricated.
Resolve by name OR Gaia source_id (id wins)

Resolved Multiple-Star System Viewer

The Gaia-resolved system containing a source (from gcns.resolvedss; systems are connected components over the resolved pairs). Pass any component — the whole system is returned. A single/unresolved star returns a clean "not Gaia-resolved (not necessarily single)" message.

Plan details
  • Backed by compute_gcns_system(source_id) → {system_id, n_components, n_pairs, any_bin/any_bound/all_bound, …, members[], pairs[]}.
  • Members not present in gcns_stars are retained (flagged), never dropped. ▶ marks the queried component.
  • Try: 61 Cygni A or Sirius A (resolved pairs) vs. Proxima Centauri (single → error).

GCNS Stars Within a Star

All GCNS stars within N ly of a center star. Unlike the SIMBAD version (which drops everything within 0.001 ly ≈ 63 AU), this keeps Gaia-resolved close companions — they're excluded only by exact source_id.

Plan details
  • compute_gcns_stars_within_star(star,source_id,limit_ly) → {center, center_x/y/z, count, stars[]}; each star carries a per-row Distance from the center.
  • Panel GcnsStarsWithinStarPanel(DiagramToggleMixin, ResultPanel) — center gold-highlighted on the map.

SIMBAD Lookup — with GCNS cross-reference NETWORK · SIMBAD

M5 enriches the existing opt-1 SIMBAD lookup. Because opt 1 already resolves the Gaia id, M5 reuses it for free (no extra network) to attach a GCNS block: the Bayesian distance with 16th/84th-percentile uncertainty shown right beside opt 1's naive 1/ϖ parallax distance. Silent when the star has no Gaia id or isn't in GCNS.

Plan details
  • The only new core code in Phase M: a non-fatal top-level "gcns" key added inside compute_simbad_lookup (parallel to "hypatia").
  • query.py parity is free — cmd_simbad_lookup serializes the core dict verbatim, so simbad-lookup output gains the "gcns" key with no dispatcher change.
  • Try a GCNS-present star (Proxima Centauri, Tau Ceti) vs. one outside the sample (Betelgeuse → block silently omitted).
