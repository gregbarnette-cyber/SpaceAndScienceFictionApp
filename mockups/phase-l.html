Side-by-Side Star Comparison

Compare 2–4 stars in one transposed table — SIMBAD properties, computed habitable-zone bounds, and Hypatia stellar/kinematic/abundance data. Per-star failures are isolated (one bad name never drops the others).

Implementation
  • Core: databases.compare_stars(names) — reuses compute_simbad_lookup + compute_hypatia_data; optional NASA pscomppars supplement to fill missing teff/radius/mass/lum.
  • HZ bounds: compute_habitable_zone(teff, luminosity) → Conservative Inner (rg) & Outer (mg).
  • GUI-only — multi-star network fan-out is not a query.py subcommand.

Exoplanet ESI Ranking presentation-only · reuses search_hwc

A leaderboard of the most Earth-like worlds in the local Habitable Worlds Catalog, ranked by Earth Similarity Index. Double-click a row to open the full HWC system view.

Implementation — no new core function
  • Calls the shipped databases.search_hwc({esi_min, habitable, habzone_con, ly_max}) (already sorted P_ESI DESC, cap 500).
  • Panel adds the 1-based Rank column and the LY conversion (S_DISTANCE × 3.26156) — pure presentation.
  • Already reachable headless via query.py search-hwc --esi-min 0.8 --habitable — so no new esi-ranking subcommand.

Stellar Evolution Timeline query.py: stellar-evolution

Evolutionary-stage durations and timeline for a main-sequence star (valid 0.1–20 M☉). Self-validating: a mass outside the range returns a clear error rather than extrapolating.

Implementation
  • Core: equations.compute_stellar_evolution(mass_solar, current_age_gyr=None) — pure math.
  • T_ms = 10¹⁰ × (1/M)^2.5 yr (mirrors core/regions.py mainSeqLifeSpan); stage fractions Pre-MS .01 · MS 1.0 · Subgiant .15 · RGB .10 · HB .10 · AGB .02.
  • Special cases: M<0.8 → MS "> 13.8 Gyr"; M>8 → AGB replaced by "Supergiant → Supernova".
  • query.py: stellar-evolution --mass-solar 1.0 [--current-age-gyr 4.6] — curated {"error"} for out-of-range mass.

Import Hypatia Cache

Batch-fetches Hypatia Catalog data for every star_systems row carrying a HIP or HD designation and stores it locally — removing the per-lookup network dependency from Star Comparison and unlocking the Fe/H filter in Star Systems Search.

⚠️ This may take several minutes (one rate-limited API call per candidate star). Resumable & idempotent (INSERT OR REPLACE); per-star errors are skipped and counted.
